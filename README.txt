Intrusion Guard 3 (IG3)
-----------------------
Install:
 1) Run IG3-Setup-3.0.0.exe
 2) Allow Windows Firewall on first launch

Use:
 - Go to Live -> Start to begin detection
 - Yellow overlay shows mode/FPS/detections
 - Settings: fill Gmail App Password and click Test Email

Diagnostics:
 - http://127.0.0.1:5123/health
 - http://127.0.0.1:5123/frame.jpg
 - http://127.0.0.1:5123/diag
